Configurar guardado en la nube (una sola vez)

Para que lo que Yuly suba se vea en todos los celulares y quede guardado, conectamos Firebase (gratis de Google). Hazlo desde tu Gmail o el de ella — solo tarda unos minutos.

  1. Entra a console.firebase.google.com y crea un proyecto (ej. Skin Beauty).
  2. Pulsa el ícono Web (</>), registra la app y copia el objeto firebaseConfig.
  3. Pega esos valores en el archivo js/firebase-config.js del sitio y vuelve a subir a GitHub/Vercel.
  4. Authentication → método Email/contraseña → Activar → Add user con el correo y contraseña de Yuly.
  5. Firestore Database → Create → modo producción → pega las reglas del archivo firestore.rules.
  6. Storage → Get started → pega las reglas del archivo storage.rules.

Después, Yuly solo entra a /admin.html con su correo y contraseña. No ve código ni Firebase.

Entrar

Acceso solo para Yuly (correo y contraseña que creaste en Firebase).
